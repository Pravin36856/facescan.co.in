# FaceSnap AI - Permanent 24/7 Server Guide

Aapke software ko kabhi band na hone aur 24/7 live rakhne ke 2 tarike hain:

---

## 🟢 Tarika 1: Aapke Computer Par Auto-Start (FREE & ACTIVE NOW)
Humne aapke computer me **Auto-Start Service** install kar di hai:
- Ab jab bhi aap apna PC/Laptop on karenge, yeh software background me apne aap shuru ho jayega.
- Iske liye aapko koi black window ya terminal kholne ki zaroorat nahi hai.
- Status check karne ke liye browser me kholein: `http://localhost:8000`

---

## 🚀 Tarika 2: Cloud Server Par Host Karna (Best for Selling to Photographers)
Kyunki aap ise photographers ko ₹4,999 me sell karne wale hain, shaadi me aane wale mehmaan raat me ya subah kabhi bhi apna photo dekh sakte hain. Agar aapka PC band ho gaya to unka link nahi khulega. Isliye Cloud Server sabse best hota hai:

### 1-Click Cloud Hosting (Render.com ya Railway.app):
1. Humne project me `Dockerfile` aur `render.yaml` ready kar diya hai.
2. [Render.com](https://render.com) ya [Railway.app](https://railway.app) par free account banayein.
3. Is folder ko GitHub par upload karke Render se connect karein.
4. Render 24 ghante 365 din bina PC on rakhe software ko live rakhega.
5. Aapko ek permanent URL milega (jaise `https://facesnap-ai.onrender.com`) jo kabhi change nahi hoga!

### Custom Domain (Aapka Apna Brand):
Aap GoDaddy / Hostinger se apna domain (jaise `apnaphotostudio.com`) lekar is server se connect kar sakte hain, jisse photographer ko lagega yeh aapka apna private branded software hai!
