# FaceScan AI (facescan.co.in)
AI Event & Wedding Photo Sharing SaaS Platform for Photographers.

## Features
- **AI Face Recognition**: High-speed multi-day face search using OpenCV YuNet & SFace.
- **Client Face Scan Portal**: Live camera selfie search with automatic ZIP photo downloads.
- **Photographer Studio Dashboard**: Bulk upload, event management, and printable QR standee generator.
- **Monetization Engine**: 1-Year Photographer Studio Pass subscription paywall with license key validation.

## Deployment
Docker and Render blueprint ready (`render.yaml`).
